# Приложение (демо-CRM): как всё разложено

**Открыть:** двойной щелчок по `index.html`, или через любой локальный сервер (адрес вида `http://localhost:...`).

**С сервером и без.** Если открыть с нашего сервера (`npm start` в папке `сервер/`, адрес `http://localhost:3000`), приложение просит логин и ПИН: пока не вошли, за окном входа ничего не видно, роль берётся от сервера. Если сервера нет (двойной щелчок по файлу или просто статичная раздача), работает старое демо: роль выбирается без ПИН.

**Два режима одной страницы:**
- **Приложение** (обычное открытие): экран на всё окно. Вид «телефон» или «компьютер» выбирается сам по ширине окна: от 900 пикселей это компьютер, уже окна это телефон. Окно потянули, и вид сменился. Тема берётся с устройства, поменять можно в окне входа (человечек вверху справа). Так же откроется на настоящем телефоне после выкладки.
- **Витрина** (`index.html?витрина`): как раньше при выборе дизайна, с рамкой телефона и кнопками «Телефон / Компьютер / Тема» сверху. Удобно показывать вид телефона на компьютере.

Шрифты пока подключены с Google Fonts, остальное работает без интернета.

```
приложение/
 ├ index.html            рама страницы (HTML): шапка, боковая панель, место для экрана, подключение всех файлов
 ├ css/                  внешний вид (CSS)
 │   tokens.css          цвета, шрифты, отступы (светлая и тёмная тема)
 │   base.css            основа: кнопки, плашки, поля, переключатели
 │   shell.css           рамка приложения, боковая панель, нижнее меню, режим «на всё окно»
 │   screens.css         вид экранов
 │   login.css           окно входа и выбор роли
 └ js/                   поведение и данные (JavaScript)
     data.js             демо-данные (придуманные): товар, заказы, сотрудники, клиенты, расходы, правила
     state.js            «тетрадь» демо (состояние st): что выбрано сейчас; сброс init()
     helpers.js          общие мелочи для всех экранов
     api.js              разговор экрана с сервером: apiCall (задать вопрос), serverProbe (есть ли сервер)
     login.js            окно входа при работе с сервером: логин и ПИН, смена временного ПИН, «вы вошли как…», выход
     payroll.js          зарплата и автоматические расходы (из них считается прибыль)
     app.js              выбор экрана, перерисовка render(), боковая панель, переходы
     events.js           реакция на нажатия, клавиши и ввод текста
     main.js             запуск: выбор режима и вида (телефон или компьютер), первая отрисовка
     screens/            по одному файлу на экран
         today, more, products, product-card, return(s), transfers, cash,
         reports, expenses, clients, sale, people, settings, orders, courier
```

Правила:
- **Порядок подключения в `index.html` важен:** данные → состояние → общее → экраны → `app.js` → `events.js` → `main.js` (запуск в конце).
- Подключено обычными скриптами, не модулями: модули не открываются двойным щелчком.
- Старая версия одним файлом: `../дизайн/каркас.html`. Это архив, не менять.
- Шрифты в папку `fonts/` положим, когда будет разрешение на скачивание.
