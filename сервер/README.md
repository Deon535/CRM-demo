# Сервер демо-CRM: памятка

Серверная часть (бэкенд). Раздаёт экран из папки `../приложение/` и отвечает на вопросы API (адреса `/api/...`). Устройство и шаги: `../план-этап-3.md`.

## Как запустить (на своём компьютере)

В терминале, находясь в папке `сервер/`:

- `npm install` — один раз: скачать готовые детали (Fastify и др.) в папку `node_modules/`.
- `npm start` — запустить сервер. В окне появятся строки журнала, окно занято, пока сервер работает.
- Открыть в браузере `http://localhost:3000` — это приложение, но уже с сервера.
- Открыть `http://localhost:3000/api/health` — ответ «сервер жив» (`ok: true`).
- `Ctrl+C` в том же окне — остановить сервер.
- `npm run dev` — то же, что `npm start`, но сервер сам перезапускается, когда вы правите его файлы.

Порт и адрес меняются переменными `PORT` и `HOST` (по умолчанию 3000 и `127.0.0.1`: сервер доступен только с этого компьютера).

## Что где лежит

- `package.json` — паспорт программы: название, команды запуска, список подключённых деталей.
- `src/app.js` — запуск сервера.
- `node_modules/` — скачанные детали, появляется после `npm install`. В git не попадает.
