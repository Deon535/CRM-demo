# Промпт: дизайн экранов демо-CRM для магазинов одежды

Формула из 4 частей (эстетика, референс, интент, рамки). Источники: `разбор-вкуса.md`, `design-system.md`, `ТЗ.md`.
Этим промптом делаем веер 1 (первый экран = два ключевых экрана) и дальше веер 2 и доведение.

---

## 1. Эстетика
Направление: **смелый минимал для рабочего приложения, без акцентного цвета.**
Термины (общие для всех вариантов; в веере 1 у каждого варианта к ним добавляется свой набор из 5–8):
- крупные плотные цифры (число-герой, межстрочный 90%, трекинг минус)
- строгая сетка, всё на своих местах
- высокий контраст, почти белый или почти чёрный фон, чернильные кнопки
- много воздуха между блоками, плотность внутри блоков
- цвет только по смыслу: красный = проблема, зелёный = хорошо
- границы тонкими линиями вместо теней
- рабочий, спокойный тон, ощущение настоящего приложения, а не сайта

Шрифты и токены не придумывать, взять из `design-system.md`: Onest для надписей, Inter Tight для цифр и денег, цвета и скругления из таблиц системы, светлая и тёмная тема обе.

## 2. Референс
Ощущение смелого минимала из разбора вкуса (семья 3): ATOM Swiss, Bryn Taylor, MacBook Neo, RDK, Nexora, Zenith Realty. Это сайты, а мы делаем приложение, поэтому берём только настроение: строгость, крупный шрифт, чистоту, высокий контраст.

> **Повторяй ощущение, а не содержание.**
Не копировать ни один референс, не переносить их блоки и композиции.

## 3. Интент
Продукт: универсальная CRM для магазинов одежды (демо, которое показывают разным магазинам). Пример заказчика: сеть из 4 магазинов мужской одежды в Дагестане.
Кто смотрит: владелец (главный зритель на показе), потом продавцы, менеджер, курьер, бухгалтер. Основное устройство телефон, на компьютере выглядит так же как приложение.
**Что должен подумать за 3 секунды: «всё под контролем».** Деньги, остатки и проблемы видны сразу, спокойно и ясно.

Содержимое двух ключевых экранов (из ТЗ):
- **Утренний экран владельца** (ТЗ 7.7): выручка по магазинам (вчера и сегодня), прибыль за месяц, расхождения в кассе, долги поставщикам, ближайшие платежи по аренде, кто сколько продал, товар, который не продаётся, сводка по возвратам, обменам и браку.
- **Экран продажи, телефон** (ТЗ 4.1): найти вещь (поиск, артикул, скан), в чеке несколько вещей, скидка в пределах роли, способ оплаты (наличные, карта, перевод), кнопка «Продано». Показывать название, размер, цвет, цену, сколько в наличии.

Данные демо: вымышленные, логично сходящиеся между экранами, на каждом экране метка «Демо».

## 4. Рамки

### ВСЕГДА
- Мобильный вид первым (ширина 375), потом компьютер. Целевое действие экрана очевидно, одна Кнопка основная.
- Главное число экрана самое большое и стоит выше остального.
- Деньги и количества: Inter Tight, пробел в разрядах, знак ₽, цифры одной ширины.
- Цвета и компоненты только из `design-system.md`, имена компонентов оттуда же.
- Отступы из системы (4 / 8 / 12 / 16 / 24 / 32 / 48), между блоками один отступ, не двойной.
- Каждый экран в светлой и тёмной теме.
- Каждая секция устроена по-разному, главное отличается весом от второстепенного (есть иерархия).
- Иконки из одного набора (линия 1,75, сетка 24).
- Числа-герои плотные: межстрочный 90%, трекинг минус. Заголовки по таблице шрифтов системы, строки соразмерны, без хвоста из одного слова.
- Разделять отступом или слэшем, не точками.
- Перечитать глазами весь текст и все числа перед сдачей.

### НИКОГДА
Весь список из `разбор-вкуса.md` (Часть А пункты 1–30 и Часть Б пункты 31–50) действует целиком. Коротко, самое опасное для CRM:
- Фиолетово-синие градиенты, градиентный текст, «AI-фиолетовый», матовое стекло, неоновое свечение, абстрактные 3D-шары и кляксы.
- Красный и зелёный для украшения (только деньги и проблемы).
- Сетка одинаковых карточек «иконка + заголовок + три строки» на весь экран; все блоки одного веса.
- Три способа выделения на одном элементе; карточка внутри карточки; один радиус и одна тень на всё.
- Длинное тире в надписях интерфейса, точки-разделители, эмодзи, символы клавиатуры вместо иконок.
- Цветная полоска сбоку карточки; цветные круги с инициалами вместо людей.
- Выдуманная статистика, отзывы, логотипы партнёров, «Lorem ipsum», серые заглушки.
- Всё по центру как документ; текст-вода («инновационные решения», «лучшее качество»).
- Микроанимации на каждый элемент, бегущая строка, карусели, «Листайте».
- Шрифт по умолчанию, свои шрифты вместо Onest и Inter Tight, свои цвета вместо токенов.

## Два приёма сверху
- **Структуру экранов предложи сам** внутри содержимого выше (порядок блоков, их вес). Навигацию и переключение ролей и магазинов не диктую: это веер 2.
- **Фото и картинки не генерировать**, оставить места. Фото товара в версии 1 нет (ТЗ раздел 9): показывать вещь текстом.

## Заказ веера 1 (для следующего шага)
Сделать 5 версий двух ключевых экранов (утренний экран владельца и экран продажи) в 5 разных направлениях внутри смелого минимала. У каждого свой набор из 5–8 терминов, рамки и «никогда» общие. Одна страница с переключением между вариантами и между светлой и тёмной темой.
